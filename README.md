# Personal Portfolio Website

This is my personal portfolio website where I have added some information about myself, my skills, projects, education and achievements.

I made this website while learning and practicing web development using HTML, CSS and JavaScript.

## About the Website

The main purpose of this portfolio is to have a simple place where I can showcase my work and skills.

It includes:

* About Me
* Skills
* Projects
* Education
* Achievements
* Contact Section
* Social Media Links

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts

## Features

* Responsive design for desktop and mobile
* Simple navigation
* Hero section
* About section
* Skills section
* Project cards
* Education and achievements sections
* Contact section
* Social media links
* Mobile-friendly layout

## Running the Project

You don't need to install anything to run this project.

Just download or clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/utkarsh-pratap-singh550/portfolio.git
```

Then open `index.html`.
